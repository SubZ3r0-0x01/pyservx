## 4. Gaps

### Critical
1. **Nothing committed to git** — whole session is uncommitted working tree.
2. **Tunnel inactive** until a provider exists: install cloudflared
   (`winget install Cloudflare.cloudflared`) or enable Tailscale Funnel or
   ngrok, then restart with `--tunnel`. No watchdog/retry if tunnel drops.
3. Saved SSH passwords stored plaintext in localStorage.
4. `/api/remote/*` lets any LAN device use the server as an outbound SSH
   pivot — needs opt-in flag or admin gate.
5. Certificate auth option doesn't truly work (paramiko ignores OpenSSH user
   certs passed as key_filename); FIDO2 blocked honestly, cert silently not.

### Functional
6. Remote download route untested over HTTP; no Range/resume; no upload-to-
   remote, no remote-folder zip, no idle reaper for session cap (8).
7. Clipboard: polling last-writer-wins (simultaneous typers clobber);
   per-path clipboards can surprise users.
8. Token manager lists full tokens forever — mask after creation.
9. No login rate-limit/lockout; no CSRF tokens; audit cookie SameSite flags.

11. Ctrl+C path skips `remote_sftp.shutdown()`/`tunnel.stop()`.
12. Ephemeral links intentionally bypass auth — holder of URL downloads.
